# 赛博老爸的 Harness 换装器

给已安装的**官方 DeepSeek Harness**添加启动动画、界面皮肤和独立桌宠。安装后在 **左下角账号菜单 → 设置 → 美化工具箱** 使用。聊天、账号、模型和任务仍由原生 Harness 负责，美化本身不需要新的 API Key。

**当前 v0.8.2。已测：macOS Apple Silicon + 官方 Harness 0.2.0-rc.2。** 安装器固定检查这个 Harness 版本；Windows、Linux、Intel Mac 及其他 Harness 版本未实测。

![极客皮肤在真实原生 Harness 中的首页](docs/screenshots/geek-hud-native-home-v081.png)

## 安装与启动

先从 [DeepSeek 官方仓库](https://github.com/deepseek-ai/deepseek-harness) 安装 **Harness 0.2.0-rc.2**，打开一次完成初始化。已有这个版本无需重装；其他版本请勿绕过检查安装。

在终端进入准备长期保存项目的位置，然后执行：

```sh
git clone https://github.com/cyberdaddyleo/deepseek-meihuaqi.git deepseek-meihuaqi
cd deepseek-meihuaqi
./run.sh setup
```

`setup` 检查官方应用版本、安装锁定依赖并构建插件。若本机没有带开发头文件的 Node.js 24+，`run.sh` 会下载官方 Node.js 24.19.0 到项目 `.runtime/` 并校验 SHA-256，不改系统 Node。首次安装依赖与 Electron 需要联网；预装素材随仓库提供，之后可离线使用。

**保存工作，等待任务结束，再用 Cmd+Q 完全退出 Harness**，然后执行：

```sh
./run.sh install
./run.sh start
```

打开 **账号菜单 → 设置 → 美化工具箱**，确认有「启动画面」「界面皮肤」「桌面宠物」三个标签。克隆或构建成功不等于已安装插件，需要完成上述安装、启动步骤。

安装通过官方插件管理能力把本地项目链接到原生桌面 profile，保留兼容检查、文件锁与失败回滚。修改前备份相关配置到 `.local/install-backups/`；不修改官方 `.app` 或签名包，不另建 Harness 数据目录。

**安装后请保留项目目录。** 原生 profile 链接到这里；移动目录前先卸载，再在新位置安装。官方应用不在默认 `/Applications/DeepSeek Harness.app` 时，先在当前终端设置真实路径，再运行以上命令：

```sh
export HARNESS_APP='/你的路径/DeepSeek Harness.app'
```

`setup`、`doctor`、安装与卸载均会检查该应用版本。GitHub「Download ZIP」通常解压为 `deepseek-meihuaqi-main`；进入这个实际解压目录，从 `./run.sh setup` 开始；命令行解压建议使用 `ditto -x -k 源码包.zip 目标目录`，避免旧版 `unzip` 损坏中文文件名。

想让本地 AI 助手代为执行，可复制 [AI 部署提示词](docs/AI部署提示词.md)。

## 预装内容

三类独立选择、保存和组合。以下 **6 个启动画面、6 套皮肤、4 个桌宠**均随仓库提供，无需另找素材。

| 类别 | 完整预设清单 |
| --- | --- |
| 启动画面 | 极客 · 系统唤醒、赛博老爸 · 蓝光启程、鲸鱼娘 · 深蓝启航、清透蓝鲸、星河微光、森林晨光 |
| 界面皮肤 | 极客 · 深海中枢、赛博老爸 · 科技深蓝、鲸鱼娘 · 深蓝霓虹、清透冰蓝、星河夜航、森林奶油 |
| 桌面宠物 | 赛博老爸、鲸鱼娘、小蓝鲸、奶油猫 |

新安装默认鲸鱼娘启动与皮肤；桌宠预选鲸鱼娘但默认不显示，在桌宠标签打开「显示桌宠」即可。已有选择、大小和位置会保留。素材、动效与校验方法见 [预装内容](docs/预装内容.md)。

每类都有「添加」入口：启动画面和桌宠可导入 PNG、JPEG、WebP、GIF、SVG，单张最多 5 MiB，每类最多 20 个自定义预设；皮肤支持十个颜色字段调整与主题 JSON 导入导出。保存后点「应用」才切换，无需改源码或构建。可试用 [小星星 SVG](examples/小星星.svg) 和 [紫藤轻雾主题](examples/紫藤轻雾.theme.json)，完整限制见 [自定义内容](docs/自定义内容.md)。

## 日常使用

**启动动画：**三个视频约 7 秒，默认从第 0 秒完整播放并播放素材声音。右下角可开关本次声音、跳过，也可按 Esc 跳过；Tab / Enter 可操作按钮。原生初始化并行，视频结束时若未就绪，继续显示官方加载状态。自动播放受限时先静音继续，可点击声音图标开启；媒体失败或「减少动态效果」开启时回退海报，启动失败时露出官方错误入口。

macOS 红色关闭按钮只是隐藏窗口，再点 Dock 或执行 `./run.sh start` 不重播。更换启动预设后，保存工作、等待任务结束，**Cmd+Q 完全退出，再启动**；只想看效果可使用工具箱的「预览」。

**界面皮肤：**即时改变真实原生侧边栏、输入框、代码区、菜单与弹窗，不重载聊天页面或重启后端。极客首页代码面板是静态装饰，在会话、设置或空间不足时收起，没有新增业务功能或系统监控指标。

**桌宠：**单击互动或唤醒，拖动调整位置，右键可切换、散步、逗一逗、打盹、暂停、调大小和关闭点击音效。默认 120 px，右键有 80 / 100 / 120 / 180 / 240 px 档位，管理页可在 80–320 px 间细调。赛博老爸和鲸鱼娘各用八姿势图集配合位移、呼吸等动效，并非完整逐帧角色动画。

完成依赖安装后，也可只启动桌宠：

```sh
./run.sh pet
```

此命令仅运行桌宠伴随进程，不启动 Harness 后端或聊天窗口。桌宠不读取其他应用输入、不做 AI 对话或主动弹窗；Harness 最小化或关闭窗口后仍可显示。右键或菜单栏 `◉` 可隐藏、重新显示或彻底退出；关闭管理窗口不等于退出。详见 [桌宠互动](docs/桌宠互动.md)。

## 更新与卸载

更新前保存工作、等待任务结束并 Cmd+Q 退出 Harness；旧桌宠也从右键菜单「退出桌宠」，避免常驻进程继续使用旧素材目录。进入原项目目录：

```sh
git pull --ff-only
./run.sh setup
./run.sh start
```

目录不变无需重复安装插件，打开后可重新开启桌宠或执行 `./run.sh pet`。若 `git pull` 提示本地修改或冲突，先处理提示，不要强制重置覆盖自己的改动。仅修改客户端代码且依赖已齐备时，可用 `./run.sh build` 构建。

卸载时先 Cmd+Q 完全退出 Harness，再执行：

```sh
./run.sh uninstall
./run.sh start
```

卸载后原生应用不再加载插件；独立桌宠仍需从自身菜单退出。`.local/` 中的偏好、自定义素材与备份保留，不删除原生会话、账号或模型配置。工具箱「恢复默认」也保留自定义素材库。

## 排查与验证范围

- **找不到工具箱：**运行 `./run.sh doctor` 检查环境；确认做过 `install`，并完整退出后重开。原生「插件」页可查看启用状态。
- **插件页卡在检查：**正常退出原生应用后运行 `./run.sh install`，它调用官方安装能力。
- **桌宠未显示：**检查美化总开关与「显示桌宠」，或执行 `./run.sh pet`；缺依赖时执行 `./run.sh setup`。
- **视频无声：**检查系统输出音量与右下角声音图标；预览使用视频原生控件。启动声音与桌宠点击音效独立。
- **图片导入失败：**检查格式、5 MiB 和像素限制。含脚本、外链、样式或嵌入图片的 SVG 会被拒绝，可改用透明 PNG；见 [自定义内容](docs/自定义内容.md)。

项目对照上游 tag `dsh-v0.2.0-rc.2`、commit `639ed015397290b3745d163aafe02ffee4aa3f84`。已有换肤、启动、自定义内容和桌宠测试记录见 [验证报告](docs/验证报告.md)，报告区分历史版本、隔离测试与原生实测。**桌宠跨应用物理拖动、透明区域点击穿透、焦点、显示器和多 Space 等实机验收仍有待测项。** 其他平台和 Harness 版本不作兼容承诺，升级官方应用前应重新验证接口。

```sh
./run.sh doctor

./run.sh test:install-browser   # 首次准备测试用 Chromium
./run.sh test:startup

```

更多专项命令与调试流程见 [验证报告](docs/验证报告.md)。原生 UI 测试仅在空闲测试会话运行，日常启动不需要调试端口。`.local/`、`.runtime/`、`node_modules/`、`.upstream/` 不应提交，其中可能包含本机配置及私有备份。
