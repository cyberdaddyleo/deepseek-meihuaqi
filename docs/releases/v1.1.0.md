# v1.1.0｜自定义启动视频

发布日期：2026-10-06。GitHub：[cyberdaddyleo/deepseek-meihuaqi](https://github.com/cyberdaddyleo/deepseek-meihuaqi)。

## 本版新增

- 原生「美化工具箱 → 启动画面 → 添加启动画面」可直接导入本地 MP4，保留已有图片入口。
- 视频上限为 50 MiB、120 秒，要求普通非碎片化 H.264 MP4（`avc1` / `avc3`），音轨推荐 AAC。不自动转码，无需安装 FFmpeg。导入时校验媒体、生成 JPEG 海报，可选择完整显示或铺满画面。
- 保存视频到本地素材库，支持预览、应用、删除、重启后继续使用；导入后移动原文件不影响播放。
- 视频保留原声，从第 0 秒完整播放，初始化提前完成不会截断；声音与跳过小图标、Esc、真实错误回退及结束清理继续有效。
- 按视频时长设置播放故障上限，让较长的自定义视频正常结束，同时保留失常媒体的退出路径。
- 自定义素材库升级为格式 2，格式 1 有效数据自动无损迁移。旧 0.8.2 程序拒读并保留新配置，防止常驻旧桌宠将视频误判为损坏记录。

6 个预装启动画面、6 套皮肤、4 个桌宠及其素材保持不变。自定义内容仅保存在本机，更新仓库不会上传用户导入的视频。

## 已有用户更新

**更新前必须正常退出 Harness 和旧桌宠。**先保存工作、等待任务完成，使用 Cmd+Q 完全退出 Harness，并从桌宠菜单选择退出；只隐藏窗口不算退出。在原项目目录执行：

```sh
git pull --ff-only
./run.sh setup
./run.sh start
```

原目录的本地 link 安装无需重复安装，已有美化设置和自定义素材保留。有本地修改或冲突时先处理，不要强制重置。不要手改自定义素材库版本号降级；旧版不认识新视频记录，需要回退时使用匹配版本的完整备份。新用户按 [README](../../README.md) 完成 `setup`、`install`、`start` 三步。

添加后先预览，再点击卡片「应用」。查看真实启动效果需保存工作并完全退出后重开；只关闭窗口不会重播。完整操作与限制见 [自定义内容](../自定义内容.md)。

## 兼容与验证

适配基线仍为 **macOS Apple Silicon + 官方 DeepSeek Harness 0.2.0-rc.2**，不增加对其他系统或客户端的兼容承诺。实际执行的构建、媒体和原生检查记录在 [验证报告](../验证报告.md)；历史测试记录不等同于本版重新验收。
