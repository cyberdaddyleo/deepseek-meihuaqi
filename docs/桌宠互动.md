# 桌宠互动

v0.6.0 桌宠选项为赛博老爸、鲸鱼娘、小蓝鲸和奶油猫。新增赛博老爸按项目 VI 制作，采用圆框眼镜、蓝色耳机、白西装与黑领带；它与 v0.5.3 已移除的小机器人是不同的预设。旧设置若仍选择机器人，会安全回退鲸鱼娘，保留大小、位置及其他偏好。桌宠会自己做小动作，也会逐渐犯困。它仍是一个本地、独立的透明悬浮窗，不依赖模型或聊天任务。

## 先启动新版桌宠

已有桌宠进程不会自动载入更新后的代码。更新源码并完成 `./run.sh setup` 后，在旧桌宠本体上右键，选择 **退出桌宠**，再从仓库目录执行：

```sh
./run.sh pet
```

「隐藏桌宠」和关闭桌宠管理窗口都不等于退出进程。菜单栏 `◉` 也提供退出入口。无需为这一步退出原生 Harness；独立启动命令不启动 Harness 后端。

## 觉得太大？直接右键缩小

在桌宠本体上 **右键 → 桌宠大小 → 小巧 · 100 px**，即可缩小；想更轻巧可以选 **迷你 · 80 px**。菜单还提供「适中 · 120 px」「大号 · 180 px」「展示 · 240 px」，并显示当前尺寸；标准档位会有选中标记。

需要细调时，进入 **右键 → 桌宠大小 → 管理页精细调节**，或在原生 **设置 → 美化工具箱 → 桌面宠物** 打开管理页。大小控制位于卡片列表上方，可以用滑块逐像素调整，也可以点击「－ / ＋」每次调整 10 px，范围为 **80–320 px**。

选择菜单档位、松开滑块或点击加减按钮后立即生效，并自动保存在本地；下次打开仍使用这个大小。**调大小无需重启**。新安装的默认大小为 120 px，已有保存的尺寸会保留。不同图片的留白不同，同一数值看起来可能略有差别。

## 它会做什么

| 操作或状态 | 反应 |
| --- | --- |
| 醒着待机 | 启动后 6–9 秒先走一圈，之后每隔 10–16 秒交替散步和随机小动作，小动作不连续重复 |
| 原地散步 | 赛博老爸左右迈步，小蓝鲸游动、奶油猫迈步，鲸鱼娘来回爬行、转身，一轮约 6 秒；不改动桌面窗口或保存的位置 |
| 45 秒未与桌宠互动 | 进入困倦状态，打哈欠，之后只偶尔张望或打哈欠 |
| 120 秒未与桌宠互动 | 进入睡眠，轻微呼吸，不再随机打断睡眠 |
| 单击本体 | 随机的小动作与短中文回应；困倦或睡着时，第一次点击先唤醒 |
| 700 毫秒内连续点击至少 3 次 | 跳跃或转圈，伴随小星光；反馈最多每 200 毫秒重启一次 |
| 拖动本体，松手 | 拖动反馈、轻轻落地，并重新开始闲置计时 |
| 右键 → 散散步 | 立即走一圈，睡着时也能唤醒；点击或拖拽可接管动作 |
| 右键 → 逗一逗 | 立即做一个互动动作，不用等待随机时机 |
| 右键 → 打个盹 | 立即睡觉，适合快速演示 |
| 右键 → 叫醒 | 唤醒并伸展一下，醒着时也会回应 |
| 右键 → 陪陪鲸鱼娘 | 选择「喂一口」「陪我工作」「打个哈欠」，立即展示对应姿势与小动作 |
| 右键 → 陪陪赛博老爸 | 选择「吃块饼干」「陪我工作」「打个哈欠」，立即展示对应姿势与小动作 |
| 右键 → 点击音效 | 选择是否播放单击时的短轻音，开关会保存在本地 |
| 右键 → 暂停动画 | 冻结动作、图片与闲置计时，暂停期间不排队积累互动 |

睡眠和困倦只按与桌宠本身的互动计时，不读取其他应用的输入，也不会因为你在另一个软件打字就自动醒来。拖拽中不会突然睡着；取消拖动不会误触点击反馈。恢复动画后继续原来的时间进度，不把暂停的时长算成闲置。

赛博老爸使用八姿势图集：站立、打哈欠、吃饼干、电脑工作、走路、睡眠、挥手点赞、被提起。鲸鱼娘的八种姿势为待机、打哈欠、吃零食、工作、爬行、睡眠、开心、被提起。姿势切换加上 CSS 位移、呼吸和摇摆带来动作感，**不是完整逐帧角色动画**。吃零食约 4 秒、工作约 5 秒，散步或爬行约 6 秒。老爸素材与制作记录见 [赛博老爸桌宠](赛博老爸桌宠.md)。

奶油猫的左右两只前爪与后脚有独立轮廓；走路时两只前爪交替摆动，洗脸和探头时抬起右前爪，另一只仍然可见。伸懒腰时双爪向两侧伸展。小蓝鲸会来回游动、摆鳍摆尾和吐泡泡。还会随机做扭扭舞、害羞探头和抖抖身体。普通小动作持续约 1–3 秒，散步约 6 秒，短文字也会随之消失。提示文字随窗口尺寸缩放，超长内容省略；小尺寸可能看不清，录屏时建议调大。暂停时隐藏短文字与装饰，保留冻结的宠物姿势。系统开启「减少动态效果」时，取消动画并保留相应的静态状态和反馈。

来回走动限制在原来的透明窗口内，只移动宠物图形，不让系统窗口游走。自定义素材中的文字或标志也会随转身镜像，建议使用不带文字的角色图片。自动散步与小动作不会刷新闲置计时，宠物仍会按时犯困、睡觉。

这些都是本地预设动作：不做 AI 对话、不读取屏幕或其他应用的文字，也不会主动打开弹窗。

**声音只跟随真实点击：**单击而没有拖动时，播放本地合成的短促轻音；快速连点限流，避免声音叠加。自动动作、睡眠和菜单操作不会主动发声。右键取消「点击音效」，或在工具箱桌宠标签中将「点击音效」设为关，即可静音。暂停动画也会停止音效。

## 自定义图片的表现

通过工具箱导入的图片使用通用的整体动作，例如来回走动与转身、扭扭舞、探头、抖动、跳跃、转圈、拖动与呼吸。程序不会自动替图片重画眼睛、嘴巴或生成新表情；内置宠物可以使用素材中专门准备的局部图形。

GIF 和动画 WebP 睡着时显示静态快照，只保留外层轻微呼吸，避免图片在睡眠状态继续跳舞。「暂停动画」会连外层动作一起冻结；继续或唤醒后恢复原图片播放，不保证从快照所在帧精确续播。

动画图片的透明点击范围仍以载入帧为准，睡眠或暂停时以快照为准。建议选用主体位置稳定的动画。素材限制及添加方法见 [自定义内容](自定义内容.md)。

## 录屏时快速走一遍

1. **右键 → 桌宠大小 → 展示 · 240 px**，便于看清短文字和局部动作；日常使用可选 80–120 px，需要其他大小时进入「管理页精细调节」。
2. 选「赛博老爸」，点 **右键 → 陪陪赛博老爸 → 吃块饼干 / 陪我工作 / 打个哈欠**，再点 **散散步** 看迈步和转身。选鲸鱼娘时用「陪陪鲸鱼娘」演示零食、工作与哈欠，散步会来回爬行；也可切换奶油猫和小蓝鲸。
3. 单击一次听轻音，然后快速连点三次；取消「点击音效」后再点一次确认静音。拖到桌面另一处，松手看被提起与落地反馈。
4. 点 **右键 → 打个盹**，展示睡眠；单击本体或点 **叫醒**。
5. 切换到导入的图片，演示同样的整体动作，以及睡眠快照。
6. 点 **暂停动画**，再点 **继续动画**。录制结束可通过 **桌宠大小 → 小巧 · 100 px** 缩回日常尺寸，或选择 **隐藏桌宠**；需要停止进程则选 **退出桌宠**。

行为状态机有独立的假时间测试。原生窗口、跨应用拖动、物理点击穿透和焦点等实机项目，统一以 [验证报告](验证报告.md) 为准；本说明不代表这些项目已全部通过。
