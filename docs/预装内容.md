视频默认从第 0 秒完整播放。初始化并行，结束或跳过后仍未就绪时继续显示官方加载状态。右下角左图标开关本次声音，右图标跳过，支持 Tab / Enter / Esc；普通按键不误跳过。管理页预览保留原生视频控件。

有声自动播放被阻止时先静音继续，点击静音图标可尝试开声；静音播放也失败、素材缺失或启用「减少动态效果」时回退海报。启动失败露出官方错误入口。隐藏窗口暂停音视频，恢复可见后继续；结束、跳过或离开时释放资源。SVG 与自定义图片在原生就绪时退出，不强制延长加载。

更换预设后需正常完全退出 Harness 再打开，红色关闭按钮只隐藏窗口。主进程和 Host 最早的启动仍由官方负责，美化在插件加载后出现。

## 桌面宠物：4 个

| 名称 | 素材与动作 |
| --- | --- |
| 赛博老爸 | 透明八姿势图集；圆框眼镜、蓝色耳机、白西装与黑领带；可吃饼干、工作、打哈欠、散步和睡觉 |
| 鲸鱼娘 | 透明八姿势图集；可吃零食、工作、打哈欠、爬行和睡觉 |
| 小蓝鲸 | SVG 蓝鲸；游动、摆鳍、吐泡泡等动作 |
| 奶油猫 | SVG 猫咪；迈步、洗脸、伸懒腰等动作 |

图集通过姿势切换、CSS 位移和呼吸等产生动作，**不是完整逐帧角色动画**。启动 6–9 秒后先走一圈，之后每隔 10–16 秒交替散步与小动作；45 秒未互动会困倦，120 秒会睡眠。单击互动或唤醒，700 毫秒内连点三次可跳跃或转圈。

右键支持「散散步」「逗一逗」「打个盹」「叫醒」、角色专项动作、切换、暂停、调大小、点击音效开关、隐藏和退出。自动动作不发出点击音效，不读取其他应用输入、不做 AI 对话，也不主动弹窗；暂停冻结动作与闲置计时。

桌宠为独立透明窗口，可用 `./run.sh pet` 启动；正常退出 Harness 不等于退出桌宠，需右键或菜单栏 ◉ 退出。互动和录屏方法见 [桌宠互动](桌宠互动.md)。

透明区域采用图形命中检测与鼠标事件转发。GIF、动画 WebP 的命中范围取载入帧，暂停或睡眠使用快照，恢复不保证精确续播。**跨应用物理拖动、透明区域点击穿透、焦点及显示器场景仍有实机待测项**，以 [验证报告](验证报告.md) 为准。

## 校验与自定义

仓库包含素材校验清单，可在仓库根目录执行：

```sh
shasum -a 256 -c assets/SHA256SUMS
```

该命令比较文件与随附清单是否一致，不代表运行或兼容测试。清单覆盖预装所用素材及保留的来源、参考文件；历史素材和参考图不代表额外可选预设。

三个标签都有「添加」入口，支持的图片、主题格式及数量和尺寸限制见 [自定义内容](自定义内容.md)。保存后点击「应用」切换，恢复默认保留自定义库。
