# 赛博老爸小标识

v0.5.2 将工具箱页头的旧机器人 SVG 替换为 `assets/cyberdad-logo.png`。原生设置和独立桌宠管理页复用同一个资源；v0.5.3 已移除旧机器人桌宠选项，此品牌标识继续保留。v0.6.0 在同一 VI 和本标识基础上新增全身 [赛博老爸桌宠](赛博老爸桌宠.md)，使用独立的八姿势图集，不改变页头标识。

参考为用户提供的赛博老爸 IP 标准三视图。标识采用正面半身像：珍珠白圆头、黑色圆框眼镜、黑色椭圆眼睛、蓝青色耳机内圈、白西装与黑领带。保持图中角色识别点，去掉全身机械细节、文字和背景，以适合 48px 页头显示。

素材：1254×1254 RGBA PNG，保留生成工具输出的透明通道。使用内置 `image_gen`，没有使用外部 API Key。文件直接复制自工具输出，没有程序重绘或抠图。已检查生成大图及原生 48px 小尺寸效果：圆框眼镜、蓝色耳机和领带可辨识，四角透明，无额外文字、背景或水印。原生渲染截图见验证报告。

替换方式：用自己的透明 PNG 覆盖同路径文件，保留方形画布和适量留白，然后执行 `./run.sh build` 并正常退出/重开 Harness。该路径通过精确白名单的本地媒体接口加载，不把大 PNG 塞进脚本。
