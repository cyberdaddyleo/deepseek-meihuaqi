# 鲸鱼娘启动音轨 · v0.7.2

鲸鱼娘启动画面现在使用用户新提供的声音，画面和约 7.082 秒的完整启动时长保持原样。启动层和管理页预览共用同一个 MP4，日常运行不需要 FFmpeg、额外音频播放器或网络服务。

## 为什么此前没有声音

原 `DeepSeek动态壁纸_deepseek_harness__720p.MP4` 虽有 AAC 音轨，解码后却全是静音：`volumedetect` 的平均与峰值均为 −91 dB。v0.7.1 修复了播放器默认静音和声音开关，但取消静音不能让静音素材发声。

用户补充的 `大家的反响很高，单独出一个视频_#deepseek设定_#治_4k.MP4` 是同一段画面，带有真实 HE-AACv2 声音。两个视频按相同时间缩小至 320×180 比较 210 帧，SSIM 为 0.993831；因此直接使用新音轨即可，不需要替换已有画面。新源音轨平均约 −8.5 dB、峰值 0 dB，属于较响的素材。

## 文件与处理

| 文件 | 内容 |
| --- | --- |
| `assets/sources/whalegirl-startup-silent.mp4` | 旧 720p MP4 的原始字节，774,720 字节；保留 H.264 画面及静音音轨作为维护源文件 |
| `assets/sources/whalegirl-startup-audio.m4a` | 从新 4K MP4 直接提取的原 HE-AACv2 音轨，不转码，不包含 4K 视频；44,100 Hz 双声道，49,714 字节 |
| `assets/whalegirl-startup.mp4` | 运行素材：原 H.264 视频数据包直接复制，使用新 AAC-LC 音轨；1280×720、约 7.081995 秒，809,740 字节 |

处理仅作用于音轨：降低 6 dB，开头 15 毫秒淡入，源声音末尾 120 毫秒淡出，再补静音至旧片结束。新声音转为 AAC-LC，以保持现有浏览器与原生 Harness 的解码兼容性；视频不重编码、不重绘、不改帧率或播放速度。

`assets/sources/` 供素材维护使用，不登记到运行时素材接口，也不由页面单独加载。播放器继续只加载 `assets/whalegirl-startup.mp4`，由视频元素保持音画同步和统一暂停、跳过、结束清理。

## 在程序里使用

更新代码后运行：

```sh
./run.sh setup
```

保存正在进行的工作，使用 **Cmd+Q 完全退出 Harness**，再执行：

```sh
./run.sh start
```

进入 **账号菜单 → 设置 → 美化工具箱 → 启动画面**，选择鲸鱼娘并应用。「预览」可以立即试听；查看真实启动需再次正常退出并启动。关闭窗口只会隐藏程序，不会重新播放。

启动默认有声，可用声音按钮关闭本次播放；浏览器策略阻止有声自动播放时，会先静音继续并提示点击开启声音。预览使用视频原生控件，可以调音量或静音。声音遵循系统输出设备与音量，和桌宠点击音效开关独立。

视频仍从第 0 秒完整播放，结束后进入真实 Harness；可点击跳过或按 Esc。隐藏窗口时音画一同暂停；关闭预览、跳过、自然结束或离开页面都会停止声音并释放视频源。

## 维护者复现

下述素材使用 FFmpeg 5.0.1 准备，需要支持 AAC 解码与编码。它只是维护工具，不加入 `package.json` 依赖，也不参与用户安装、启动或播放。其他 FFmpeg 版本可能生成不同封装字节，校验和应以仓库已交付文件为准。

在仓库根目录，将新 4K 文件的实际路径赋给 `WHALEGIRL_AUDIO_SOURCE`。包含空格、中文或 `#` 的路径必须放在引号内：

```sh
WHALEGIRL_AUDIO_SOURCE='/实际路径/大家的反响很高，单独出一个视频_#deepseek设定_#治_4k.MP4'
ffmpeg -i "$WHALEGIRL_AUDIO_SOURCE" \
  -map 0:a:0 -vn -c:a copy -map_metadata -1 -movflags +faststart \
  assets/sources/whalegirl-startup-audio.m4a
```

然后从两个维护源文件合成运行 MP4，先另存为新文件：

```sh
ffmpeg -i assets/sources/whalegirl-startup-silent.mp4 \
  -i assets/sources/whalegirl-startup-audio.m4a \
  -map 0:v:0 -map 1:a:0 -c:v copy \
  -c:a aac -profile:a aac_low -b:a 160k -ar 44100 -ac 2 \
  -af 'aresample=44100:first_pts=0,volume=-6dB,afade=t=in:st=0:d=0.015,afade=t=out:st=6.891995:d=0.12,apad=whole_dur=7.081995,atrim=duration=7.081995' \
  -t 7.081995 -map_metadata -1 -movflags +faststart \
  assets/whalegirl-startup-rebuilt.mp4
```

`aresample` 的 `first_pts=0` 补齐 HE-AAC 解码起点延迟，使声音从视频时间轴第 0 秒对齐；`apad` 只补齐短于旧视频的尾部。不要添加 `-shortest`，避免音轨缩短完整片头。去除容器继承元数据不改变原 H.264 画面数据包。

试听并检查新文件后，才替换 `assets/whalegirl-startup.mp4`，重新构建并正常退出、重开 Harness。不要覆盖用户提供的源视频。
