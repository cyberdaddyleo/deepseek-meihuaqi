1. `./run.sh pet`，测试三种宠物、缩放、点击、拖拽、右键暂停/继续及退出；重开确认位置。
2. 在项目目录执行 `python3 -m http.server 3189 --bind 127.0.0.1 --directory tests`，普通浏览器打开 `http://127.0.0.1:3189/manual-pet.html`。
3. 把宠物拖到页面上方。点身体时底层计数不增加；点同一透明窗口的空白角落时计数增加；重复拖动后与菜单关闭后再检查。
4. 在底层输入框连续输入，操作宠物后检查输入焦点；最小化 Harness，确认宠物继续存在。记录真实系统叠放截图。
5. 隐藏宠物后使用菜单栏 `◉` 重新显示，再选择退出，确认伴随进程停止。关闭桌宠管理窗只关闭管理窗。
