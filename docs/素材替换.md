# 素材替换

## 在工具箱里添加

普通用户无需编辑源码。在原生 **设置 → 美化工具箱** 的「启动画面」「界面皮肤」「桌面宠物」三个标签点击「添加」，即可导入自己的内容。

- 启动画面、桌宠支持本地 PNG、JPEG、WebP、GIF、SVG，每张最多 5 MiB，每类最多 20 个自定义预设。
- 皮肤支持十色编辑和主题 JSON 导入、导出，影响原生 Harness 的真实主题令牌。
- 保存后再点击卡片「应用」；删除已应用预设只让该模块回到默认。
- 「恢复默认」保留自定义库。导入文件位于 `.local/custom-assets/`，元数据位于 `.local/custom-presets.json`。

完整操作、JSON 格式和 SVG 限制见 [自定义内容](自定义内容.md)。可直接试用 [紫藤轻雾主题](../examples/紫藤轻雾.theme.json) 与 [小星星 SVG](../examples/小星星.svg)。日常导入无需重新构建或重启后端。

## 更新随仓库分发的内置预设

维护者仍可在 `src/presets.mjs` 集中更新内置配置。每项有稳定 ID、中文名称、预览资源及实际配置或素材路径。

- **皮肤：**改 `themes[].palette`。`themeTokens()` 将色板映射为原生 Harness 令牌，管理卡片使用同一份颜色。新增主题通常只需增加配置对象及预览资源；带背景图的主题还使用 `wallpaper` 指向本地 PNG。背景不应包含画死的输入框、按钮或菜单。
- **启动画面：**原有预设使用 `splashes[].asset` 指向的本地 SVG；极客、赛博老爸与鲸鱼娘分别使用 `assets/geek-startup.mp4`、`assets/cyberdad-startup.mp4`、`assets/whalegirl-startup.mp4` 和对应的 PNG 海报，并声明 `mediaType: "video"`。SVG 动画规则在 `src/scenes.css`。新增动效时增加对应的 `scene` 样式，检查真实启动页不会遮挡加载与错误状态。
- **桌宠：**小蓝鲸与奶油猫读取 `pets[].asset` 指向的本地 SVG；赛博老爸与鲸鱼娘各自读取四列、两行的透明 PNG 八姿势图集，预设中用 `sprite: {columns: 4, rows: 2}` 声明布局。内置动画使用的分组与类可参考 `assets/cat.svg`、`whale.svg` 和 `desktop/pet.css`。保持透明背景，避免覆盖整张画布的透明矩形影响鼠标命中。

保持旧 ID 可兼容已有设置。删除预设后设置会回退默认；桌宠素材缺失时先回退小蓝鲸，再使用内嵌的小蓝鲸应急 SVG。随包素材均可本地读取，不需要外部视频、CDN 或 API Key。

修改内置素材或代码后执行：

```sh
./run.sh build
```

然后完全退出并重新打开原生 Harness；正在运行的独立桌宠也应退出后重开。较小的内置 SVG 在构建时嵌入插件；MP4、壁纸 PNG 和姿势 PNG 保持独立文件，通过原生受鉴权的固定素材接口读取，桌宠读取同一组本地 `assets/` 文件。不要放入未经许可的角色、私有图片或外部脚本；通过自定义导入功能分发的 SVG 应符合 [安全子集](自定义内容.md#文件限制与安全)。

## 替换鲸鱼娘素材

| 文件 | 用途与要求 |
| --- | --- |
| `assets/whalegirl-startup.mp4` | 本地 H.264/AAC-LC MP4；1280×720、约 7.082 秒，v0.7.2 保留原画面并接入用户新音源，默认有声，从第 0 秒完整播放结束后再进入工作界面；正常播放应短于当前 15 秒故障上限 |
| `assets/sources/whalegirl-startup-silent.mp4` | 原 720p 视频，774,720 字节；用于保留原画面及来源，音轨本身全静音，不直接播放 |
| `assets/sources/whalegirl-startup-audio.m4a` | 从用户新 4K 视频直接提取的 HE-AACv2 原音轨；维护源文件，不单独加载或作为运行时音频播放器使用 |
| `assets/whalegirl-wallpaper.png` | 界面背景与视频海报；当前 1586×992。保持左侧足够安静，避免背景文字或按钮与真实界面混淆 |
| `assets/whalegirl-atlas.png` | 透明 PNG 姿势图；当前 1774×887，宽高比 2:1，四列两行。每格同角色、相近比例，并保留安全透明留白 |

姿势按从左到右、从上到下排列：待机、哈欠、吃零食、工作、爬行、睡眠、开心反馈、被提起。渲染器选择相应的一格，再加 CSS 位移或呼吸；不要把八格理解为连续播放的视频帧。普通自定义图片仍使用通用整体动作，导入界面目前不接受 MP4 或多姿势配置。

保持现有路径覆盖文件后重新构建并重开程序即可；若改路径，需同时更新 `src/presets.mjs`、`src/catalog.mjs` 的内置素材映射和 `plugin/builtin-media.mjs` 的白名单。该接口只读取明确登记的本地文件，不接受任意路径。

鲸鱼娘旧片的音轨实际全静音，不能仅靠取消静音修复。v0.7.2 将新音源转为 AAC-LC、衰减 6 dB，做 15 毫秒淡入和源末 120 毫秒淡出，再补齐原片时长；视频数据包直接复制。可复现命令见 [鲸鱼娘启动音轨](鲸鱼娘启动音轨.md)。FFmpeg 只用于维护素材，不是安装或运行依赖，运行仍由同一个视频元素同步播放音画。

原视频和新音源来自用户，壁纸和姿势图按用户参考图使用内置图像生成工具编辑。它们的原始授权尚未确认，不自动适用项目 MIT 许可证。替换和分享前应确认素材权限；详见 [来源声明](../THIRD_PARTY_NOTICES.md)、[鲸鱼娘主题](鲸鱼娘主题.md) 和 [生成记录](鲸鱼娘素材生成.md)。

## 替换赛博老爸启动与皮肤

| 文件 | 用途与要求 |
| --- | --- |
| `assets/cyberdad-startup.mp4` | 用户原片，1918×1080、约 7.072 秒；从第 0 秒完整播放，默认播放原片声音，结束后进入真实 Harness。替换片应短于当前 15 秒播放故障上限 |
| `assets/cyberdad-wallpaper.png` | 1585×992，皮肤背景、管理卡片预览与视频回退海报；机器人在右侧，左侧保持深蓝留白，避免静态按钮、文字和边框 |
| `assets/cyberdad-reference.png` | 原始参考图，1586×992，仅用于保留设计依据；不是运行时壁纸 |

皮肤的十色配置在 `src/presets.mjs` 的 `themes` 中，启动视频配置在 `splashes` 中，两者 ID 均为各自分类下的 `cyberdad`，可独立选择。仅更换同路径素材时，重新构建并正常 Cmd+Q 退出再启动即可；增加媒体文件名还需更新 `src/catalog.mjs` 与 `plugin/builtin-media.mjs` 的固定白名单。原生 Host 会缓存已加载模块，更新后仅关闭窗口不能加载新目录。

三段内置视频与管理页预览默认允许声音（播放器 `volume = 1`），最终响度由素材与系统输出音量决定；鲸鱼娘从 v0.7.2 起使用已接回声音并降低响度的新素材，极客和赛博老爸仍使用用户原片。替换时请实际解码检查音轨是否有声音，而不只是检查是否存在音轨，并避免异常响度。启动层可开关本次播放的声音，有声自动播放被策略拒绝时静音继续并提示点击开启；隐藏窗口时暂停音视频，完成、跳过或退出时停止声音并释放资源。管理页预览使用原生视频控件，自动播放受阻时可点击视频播放按钮；关闭预览即停止声音并释放视频。无音轨素材仍可正常显示视频。

不要直接把参考图整张叠在真实界面上。应保留角色与背景，并由 Harness 自己的侧边栏、输入框、菜单和消息组件显示内容；皮肤负责颜色、背景和受控装饰。来源、完整背景编辑提示词和原片校验和见 [赛博老爸主题](赛博老爸主题.md)。

## 替换极客启动与皮肤

| 文件 | 用途与要求 |
| --- | --- |
| `assets/geek-startup.mp4` | 用户原片，H.264/AAC-LC，3184×1792、约 7.072 秒；保留原画面及音效，从第 0 秒完整播放，结束后进入真实 Harness；替换片应短于当前 15 秒播放故障上限 |
| `assets/geek-wallpaper.png` | 极客皮肤背景、管理卡片预览与视频回退海报；保留青蓝地球、少量红色连接点和技术网格，避免静态按钮、假日志、状态数字或模型名称 |
| `assets/geek-reference.png` | 用户原始《深海智能中枢界面.png》，1672×941；仅保留设计依据，不作为运行时界面 |

启动和皮肤的 ID 均为各自分类下的 `geek`，在 `src/presets.mjs` 分别配置，互不绑定。视频使用 `videoFit: "contain"` 显示完整画幅，窗口比例不同会留暗边；默认开启原片音效，并沿用声音开关、跳过、隐藏时暂停及结束清理。皮肤基色为 `#050c12`，令牌映射与背景规则集中在 `src/wallpaper-theme.mjs`，真正的输入框、代码区、菜单与消息由 Harness 渲染。

v0.8.1 的首页代码装饰在 `src/geek-hud.mjs`：场景代码、灵感序列与创意脚本由同一模块生成，管理卡片复用其中的场景代码。修改文案或语法颜色时保持它是明确的静态视觉内容，不写成实时任务日志；保留不接收点击和基于原生标题、输入框的 CSS anchor 布局。主区小于 820×720 px 时收起，标题上方或输入框下方可用空间不足 160 px 时分别隐藏整卡；会话、设置或弹窗出现时隐藏。不要把这些文本再次画进壁纸，也无需新增轮询或持续动画。

原生 `.md-code-block`、终端及工具卡的极客样式集中在 `src/geek-content-theme.mjs`。替换配色或细边框时保留原生复制、代码滚动、展开与状态逻辑，装饰角标不用于表达真实错误。该版本不改启动视频与音轨。

替换同名素材后重新构建，正常 Cmd+Q 完全退出再启动；新增文件名时还需更新 `src/catalog.mjs` 与 `plugin/builtin-media.mjs` 的固定白名单。若调整影片时长或尺寸，同步更新 `tests/video-startup.mjs` 中的媒体元数据、校验和与故障上限，不应仅靠延长等待掩盖视频错误。完整规格与来源见 [极客主题](极客主题.md)。

已有依赖时执行 `./run.sh build` 即可构建本次样式更新，再 Cmd+Q 正常退出并执行 `./run.sh start`。升级前若桌宠仍在运行，应先从右键菜单或菜单栏正常退出桌宠，避免旧进程保留旧预设目录；重新打开后可在工具箱开启桌宠，尺寸与位置保留。

## 替换赛博老爸桌宠

`assets/cyberdad-atlas.png` 是 1774×887 的透明 PNG，使用与鲸鱼娘相同的四列两行布局。八格从左到右、从上到下依次为：站立、哈欠、吃饼干、电脑工作、走路、睡眠、挥手点赞、拖拽。每格保持角色比例相近，四周留出透明安全间距，头、手、脚和道具都不要跨格；程序按等分坐标裁取每格，并按当前姿势的透明度判断鼠标命中。

同路径替换后执行 `./run.sh build`，再完全退出并重开桌宠。若改变姿势顺序，需要同时修改 `desktop/pet.mjs` 的帧映射；仅换画风而保留顺序不需要改动作逻辑。新增其他内置角色还需登记预设与媒体白名单。完整参考来源、生成提示词和效果说明见 [赛博老爸桌宠](赛博老爸桌宠.md)。
