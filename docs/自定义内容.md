# 添加自己的启动画面、皮肤和桌宠

在原生 DeepSeek Harness 打开 **左下角账号菜单 → 设置 → 美化工具箱**。三个标签都有「添加」按钮，新增内容进入该标签的卡片列表。保存只是加入素材库，点击卡片的「应用」才会切换当前选项。

日常导入不需要修改源码、重新构建或重启后端。三个分类独立，能够自由组合。桌宠独立模式 `./run.sh pet` 的管理窗口也能添加桌宠，使用同一个本地素材库。

## 启动画面

1. 进入「启动画面」，点击「添加启动画面」。
2. 填写名称，选择本地 PNG、JPEG、WebP、GIF 或 SVG 图片。
3. 选择「轻柔漂浮」「星点微光」或「晨光飘动」，设置背景颜色。
4. 点击「保存到我的预设」，再用卡片的「预览」查看效果，满意后点击「应用」。

静态图片会搭配选定的装饰动效；GIF、动画 WebP 保留图片本身的动画。下一次原生 Harness 启动加载页使用所选内容，完成后立即进入真实工作界面。导入图片不会延长初始化，也不会改变原生错误和恢复流程。

可以直接选择仓库里的 [小星星.svg](../examples/小星星.svg) 体验。SVG 必须符合下方的安全子集；不支持外部视频、HTML 页面或自行编写的动画脚本。

## 界面皮肤

1. 进入「界面皮肤」，点击「添加界面皮肤」。
2. 填写名称，从一套内置皮肤开始，选择浅色或深色模式。
3. 用颜色选择器调整主背景、面板与输入框、侧边栏、悬停背景、选中背景、主要文字、次要文字、强调色、边框和代码区域。预览使用同一组主题令牌。
4. 保存后点击新卡片的「应用」，原生聊天与工作界面即时换肤。

也可点击「导入主题 JSON」，选择 [紫藤轻雾.theme.json](../examples/紫藤轻雾.theme.json)。导入后仍可修改名称和颜色，最后保存。文件不能超过 **32 KiB**，结构如下，十个颜色字段均必填：

```json
{
  "version": 1,
  "kind": "theme",
  "name": "紫藤轻雾",
  "scheme": "light",
  "palette": {
    "base": "#faf7ff",
    "surface": "#ffffff",
    "sidebar": "#f0eaf8",
    "soft": "#f1ebfa",
    "selected": "#e4daf5",
    "text": "#352d4a",
    "muted": "#706581",
    "accent": "#6d4fad",
    "border": "#ded4ec",
    "code": "#f1ecf8"
  }
}
```

`scheme` 只能是 `light` 或 `dark`，颜色只能是 `#rrggbb`。保存时检查正文和背景的对比度至少为 4.5:1，次要文字及强调色的主要背景对比度至少为 3:1；不满足时会提示需要调整的颜色。

每张皮肤卡片的「导出配色」可以下载 JSON；添加窗口的「导出当前配色」可以保存尚未入库的编辑结果。要修改已经保存的皮肤，可导出后重新导入，改名和调色后另存，确认应用成功再删除旧卡片。JSON 只包含名称、明暗模式和颜色，不包含账号、会话或密钥。

## 桌面宠物

1. 进入「桌面宠物」，点击「添加桌面宠物」。
2. 选择图片并填写名称；推荐带透明背景、四周适当留白的 PNG、WebP 或 SVG。
3. 保存、应用，然后打开「显示桌宠」。可以继续调整尺寸、拖动、点击和使用右键菜单。

导入的是系统透明悬浮窗使用的素材，原生 Harness 最小化后仍可显示。自定义图片使用通用的整体漂浮、摇动、跳跃、转圈及拖动落地反馈，不会自动重绘眼睛、嘴巴或生成新表情。右键菜单可以切换已导入的宠物，也可以「逗一逗」「打个盹」「叫醒」。

醒着时先在 6–9 秒后散步，之后每隔 10–16 秒交替来回走动与随机小动作（扭扭舞、探头、抖动等）；45 秒未互动会困倦，120 秒会睡觉。第一次点击困倦或睡着的宠物会唤醒；700 毫秒内连点三次可以触发跳跃或转圈。完整说明和录屏顺序见 [桌宠互动](桌宠互动.md)。

GIF 和动画 WebP 可播放，但第一版不逐帧计算透明区域：正常播放时，鼠标命中使用**图片载入时的画面**；暂停时使用暂停快照。主体大幅移动或每帧轮廓差异很大的动画，点击范围可能与当前帧不完全重合。优先使用位置稳定的动画。

睡眠时同样显示静态快照，只保留整体轻微呼吸；「暂停动画」则连外层动效和闲置计时一起冻结。恢复或唤醒后重新显示原图继续播放，**不保证从快照所在帧精确续播**。透明命中的机制已做自动化检查，跨应用实际点击穿透与拖动的验收状态以 [验证报告](验证报告.md) 为准。

## 文件限制与安全

- 图片格式：PNG、JPEG、WebP、GIF、SVG。按文件实际内容校验，修改扩展名不能绕过校验。
- 每张图片最多 **5 MiB（5,242,880 字节）**，宽高各不超过 **8192 像素**，总像素不超过 **3200 万**。
- 每个分类最多保存 **20 个自定义预设**，内置预设不占此额度。名称为 1–40 个字符。
- 自定义功能不加载 HTML 页面、不执行用户 CSS 或 JavaScript，不支持远程素材地址。
- SVG 作为图片读取，绝不将导入内容插入页面作为可执行标记。允许基础图形、路径、分组、渐变和裁剪等被动矢量元素；拒绝 `script`、事件属性、外链、`foreignObject`、DOCTYPE、样式标签/属性、嵌入图片和 SVG 动画标签。部分设计软件导出的复杂 SVG 需要先简化，或导出为透明 PNG；文字建议转为路径。
- 素材全部保存在本地，不需要 API Key。分享文件前请确认拥有素材的使用和分发权。

## 删除、恢复和备份

自定义卡片提供「删除」，再次确认后移除本地副本。若删除的是正在应用的内容，只有该分类回到默认：v0.5.0 的皮肤回到「鲸鱼娘 · 深蓝霓虹」，启动画面回到「鲸鱼娘 · 深蓝启航」，宠物回到「鲸鱼娘」。其他分类、桌宠开关和尺寸保持原值。内置预设不能删除。

「恢复默认」恢复美化选项，**保留自定义素材库**；「关闭美化」也不删除素材。原生 Harness 的会话、模型配置和任务数据均不受影响。

| 仓库内路径 | 内容 |
| --- | --- |
| `.local/appearance.json` | 当前选择、开关、桌宠大小和位置 |
| `.local/custom-presets.json` | 三类自定义预设的元数据 |
| `.local/custom-assets/` | 导入图片的本地副本和生成的主题预览 |

导入后移动或删除原始图片不会影响已保存的副本。备份自定义库时应一起保存 `custom-presets.json` 和 `custom-assets/`；需要保留当前选择时再加上 `appearance.json`。不要提交整个 `.local`，它还可能包含本机配置及插件安装备份。

配置或素材缺失、损坏时，工具箱保留损坏配置的备份，忽略不可用预设并让已选项回退默认。发现更高版本的配置时会提示升级并保留原文件，不静默覆盖。请优先通过界面管理内容，不要手改 ID 或素材路径。
