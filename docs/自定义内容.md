# 添加自己的启动画面、皮肤和桌宠

在原生 DeepSeek Harness 打开 **左下角账号菜单 → 设置 → 美化工具箱**。三个标签都有「添加」按钮，新增内容进入该标签的卡片列表。保存只是加入素材库，点击卡片的「应用」才会切换当前选项。

日常导入不需要修改源码、重新构建或重启后端。三个分类独立，能够自由组合。桌宠独立模式 `./run.sh pet` 的管理窗口也能添加桌宠，使用同一个本地素材库。

## 启动画面

### 添加自己的视频（v1.1.0）

1. 进入「启动画面」，点击「添加启动画面」。
2. 填写名称，选择本地 **MP4 视频**。单个视频最多 **50 MiB、120 秒**，要求 H.264 视频编码，音轨推荐 AAC；无音轨视频也可以使用。
3. 等待视频读取、实际解码和海报生成，检查视频预览。选择完整显示（`contain`，可能留边）或铺满画面（`cover`，可能裁切）。
4. 点击「保存到我的预设」。在新卡片中「预览」完整视频，确认声音和画面，再点击「应用」。
5. 保存工作并等待任务结束，用 **Cmd+Q 完全退出 Harness**，再运行 `./run.sh start` 查看真实启动效果。只关闭窗口或切换会话不会重播。

导入保留视频原声，不重新编码，也不需要安装 FFmpeg。浏览器从解码后的画面生成 JPEG 海报，供卡片和播放失败时使用。文件会复制到本地素材库，导入完成后移动原 MP4 不影响下次播放。保存只是入库，不会自动打断当前任务或更改已选片头。

启动时从第 0 秒播放，正常播放以视频的结束事件退场；原生初始化提前完成不会截断视频。右下角是声音和跳过小图标，也可按 Esc 跳过。视频结束或被跳过时若 Harness 仍在初始化，继续显示真实加载状态；出现原生错误时显示官方错误及恢复入口。媒体无法播放或卡住会回退，不会用片头无限遮住程序。启用系统「减少动态效果」时使用海报。

推荐先导入较短视频，避免每次冷启动都播放很长片头。更长视频仍可随时跳过。音频是否有声取决于源文件、系统输出音量及播放策略；自动有声播放受限时会静音继续，可点击声音图标开启。视频不支持远程链接、在线视频页面或其他容器格式；仅修改文件扩展名不能转换编码。

### 添加图片

同一入口也接受本地 PNG、JPEG、WebP、GIF 或 SVG。选择图片后可选「轻柔漂浮」「星点微光」或「晨光飘动」，设置背景颜色，再保存、预览和应用。

静态图片搭配选定的装饰动效；GIF、动画 WebP 保留图片本身的动画。图片模式完成初始化后立即进入真实工作界面，不额外延长启动。可以直接选择仓库里的 [小星星.svg](../examples/小星星.svg) 体验。SVG 必须符合下方的安全子集；不支持 HTML 页面或自行编写的动画脚本。

## 界面皮肤

1. 进入「界面皮肤」，点击「添加界面皮肤」。
2. 填写名称，从一套内置皮肤开始，选择浅色或深色模式。
3. 用颜色选择器调整主背景、面板与输入框、侧边栏、悬停背景、选中背景、主要文字、次要文字、强调色、边框和代码区域。预览使用同一组主题令牌。
4. 保存后点击新卡片的「应用」，原生聊天与工作界面即时换肤。

也可点击「导入主题 JSON」，选择 [紫藤轻雾.theme.json](../examples/紫藤轻雾.theme.json)。导入后仍可修改名称和颜色，最后保存。文件不能超过 **32 KiB**，结构如下，十个颜色字段均必填：

```json
{
  "version": 1,
  "kind": "theme",
  "name": "紫藤轻雾",
  "scheme": "light",
  "palette": {
    "base": "#faf7ff",
    "surface": "#ffffff",
    "sidebar": "#f0eaf8",
    "soft": "#f1ebfa",
    "selected": "#e4daf5",
    "text": "#352d4a",
    "muted": "#706581",
    "accent": "#6d4fad",
    "border": "#ded4ec",
    "code": "#f1ecf8"
  }
}
```

`scheme` 只能是 `light` 或 `dark`，颜色只能是 `#rrggbb`。保存时检查正文和背景的对比度至少为 4.5:1，次要文字及强调色的主要背景对比度至少为 3:1；不满足时会提示需要调整的颜色。

每张皮肤卡片的「导出配色」可以下载 JSON；添加窗口的「导出当前配色」可以保存尚未入库的编辑结果。要修改已经保存的皮肤，可导出后重新导入，改名和调色后另存，确认应用成功再删除旧卡片。JSON 只包含名称、明暗模式和颜色，不包含账号、会话或密钥。

## 桌面宠物

1. 进入「桌面宠物」，点击「添加桌面宠物」。
2. 选择图片并填写名称；推荐带透明背景、四周适当留白的 PNG、WebP 或 SVG。
3. 保存、应用，然后打开「显示桌宠」。可以继续调整尺寸、拖动、点击和使用右键菜单。

导入的是系统透明悬浮窗使用的素材，原生 Harness 最小化后仍可显示。自定义图片使用通用的整体漂浮、摇动、跳跃、转圈及拖动落地反馈，不会自动重绘眼睛、嘴巴或生成新表情。右键菜单可以切换已导入的宠物，也可以「逗一逗」「打个盹」「叫醒」。

醒着时先在 6–9 秒后散步，之后每隔 10–16 秒交替来回走动与随机小动作（扭扭舞、探头、抖动等）；45 秒未互动会困倦，120 秒会睡觉。第一次点击困倦或睡着的宠物会唤醒；700 毫秒内连点三次可以触发跳跃或转圈。完整说明和录屏顺序见 [桌宠互动](桌宠互动.md)。

GIF 和动画 WebP 可播放，但第一版不逐帧计算透明区域：正常播放时，鼠标命中使用**图片载入时的画面**；暂停时使用暂停快照。主体大幅移动或每帧轮廓差异很大的动画，点击范围可能与当前帧不完全重合。优先使用位置稳定的动画。

睡眠时同样显示静态快照，只保留整体轻微呼吸；「暂停动画」则连外层动效和闲置计时一起冻结。恢复或唤醒后重新显示原图继续播放，**不保证从快照所在帧精确续播**。透明命中的机制已做自动化检查，跨应用实际点击穿透与拖动的验收状态以 [验证报告](验证报告.md) 为准。

## 文件限制与安全

- 图片格式：PNG、JPEG、WebP、GIF、SVG。按文件实际内容校验，修改扩展名不能绕过校验。
- 视频格式：MP4，单个最多 **50 MiB（52,428,800 字节）**，时长不超过 **120 秒**。导入时检查文件内容与可播放性，无法读取视频画面或生成海报时不保存预设。要求普通非碎片化 MP4、H.264（`avc1` / `avc3`）视频，推荐 AAC 音轨。不接受 H.265/HEVC、MOV、碎片化 MP4 或流媒体分段文件；不自动转码，也不需要安装 FFmpeg。
- 每张图片最多 **5 MiB（5,242,880 字节）**，宽高各不超过 **8192 像素**，总像素不超过 **3200 万**。
- 每个分类最多保存 **20 个自定义预设**，内置预设不占此额度。名称为 1–40 个字符。
- 自定义功能不加载 HTML 页面、不执行用户 CSS 或 JavaScript，不支持远程素材地址。
- SVG 作为图片读取，绝不将导入内容插入页面作为可执行标记。允许基础图形、路径、分组、渐变和裁剪等被动矢量元素；拒绝 `script`、事件属性、外链、`foreignObject`、DOCTYPE、样式标签/属性、嵌入图片和 SVG 动画标签。部分设计软件导出的复杂 SVG 需要先简化，或导出为透明 PNG；文字建议转为路径。
- 素材全部保存在本地，不需要 API Key。分享文件前请确认拥有素材的使用和分发权。

## 删除、恢复和备份

自定义卡片提供「删除」，再次确认后移除本地副本。若删除的是正在应用的内容，只有该分类回到默认：皮肤回到「鲸鱼娘 · 深蓝霓虹」，启动画面回到「鲸鱼娘 · 深蓝启航」，宠物回到「鲸鱼娘」。其他分类、桌宠开关和尺寸保持原值。内置预设不能删除。

「恢复默认」恢复美化选项，**保留自定义素材库**；「关闭美化」也不删除素材。原生 Harness 的会话、模型配置和任务数据均不受影响。

| 仓库内路径 | 内容 |
| --- | --- |
| `.local/appearance.json` | 当前选择、开关、桌宠大小和位置 |
| `.local/custom-presets.json` | 三类自定义预设的元数据 |
| `.local/custom-assets/` | 导入图片、视频的本地副本、视频海报和生成的主题预览 |

导入后移动或删除原始图片、视频不会影响已保存的副本。备份自定义库时应一起保存 `custom-presets.json` 和 `custom-assets/`；需要保留当前选择时再加上 `appearance.json`。不要提交整个 `.local`，它还可能包含本机配置及插件安装备份。

v1.1.0 的自定义素材库格式为 **2**。升级时会自动读取并无损迁移格式 1 的有效图片、皮肤和桌宠，不需要重新导入。更新前请正常完全退出 Harness 和旧桌宠；旧版 0.8.2 会拒读较新格式并保留原文件，防止将新视频预设误当损坏内容清理。**不要手改 `custom-presets.json` 的版本号降级**；要恢复旧版，请使用与旧版匹配的完整备份，避免丢失新视频记录。

配置或素材缺失、损坏时，工具箱保留损坏配置的备份，忽略不可用预设并让已选项回退默认。发现更高版本的配置时会提示升级并保留原文件，不静默覆盖。请优先通过界面管理内容，不要手改 ID 或素材路径。
