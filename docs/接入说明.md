# 原生接入说明

目标：macOS 官方 DeepSeek Harness 0.2.0-rc.2。对应上游 tag `dsh-v0.2.0-rc.2`、commit `639ed015397290b3745d163aafe02ffee4aa3f84`。实测窗口协议为 `dsh-app://app/`，原生主进程位于 `/Applications/DeepSeek Harness.app`。前一版独立 Electron 聊天壳已移除。

| 接入点 | 本项目使用方式 |
| --- | --- |
| 组合包 `dsh.bundle.patch` | `cordis.patch.yml` 只插入 `cyberdaddy-dressup` 一个插件条目 |
| 客户端 `dsh.client` 与 ModuleLoader 工厂 | 构建一个插件包，React 复用原生共享模块，不打包第二个 React |
| `ctx.slots` 的 `settings.section` | 向原生设置添加“美化工具箱” |
| `ctx.theme.register` / `setTheme` | 集中替换原生 `--dsw-*` 设计令牌，保留上游明暗语义与语法高亮 |
| `ctx.connection.fetch.register` | `/api/cyberdaddy` 接入原生鉴权和协议转发，不新增监听端口 |
| `webserver/index-inject` | 向原生文档注入本地设置与启动脚本；视频使用独立装饰层，SVG 使用真实 BootPage；初始化、错误和恢复仍由官方处理 |
| 原生 package operation `runPluginCommand` | 安装/卸载本地 link 包，执行官方兼容检查、加锁与失败回滚 |
| 独立 Electron 伴随进程 | 只承载透明系统桌宠与其管理窗口，不承载聊天界面，不启动 Harness 后端 |

官方包内 `dsh-plugin-manager` 的 `operations` 导出在 `lib/types/operations.js`。安装脚本仅用已安装应用的 Node 运行时读取该模块；不提取、替换或重新签名安装包。客户端 generic RPC 的任意前缀注册在这个已发布版本中遇到 `webServer` 依赖限制，因此改用官方已有的受鉴权 `/api` 精确路由，没有放宽认证或来源检查。

启动状态观察该固定版本的 `[data-dsh-boot]` 与 `[data-dsh-boot-spinner]`，就绪还要求原生主界面或编辑器已挂载。v0.5.2 的鲸鱼娘视频由 `plugin/video-startup.mjs` 在同一个原生文档中创建独立的固定装饰层，不再依附于会被 React 接管的 BootPage。实际工作界面照常初始化，装饰层只控制呈现，不阻塞业务启动。旧 SVG 和自定义图片仍在 BootPage 移除时立即清理。

鲸鱼娘启动从原 MP4 第 0 秒开始，保留完整约 7.08 秒画面。正常退场由真实 `ended` 事件触发，原生 `ready` 仅更新加载状态，不缩短播放；结束后淡出 180 毫秒。如果原生仍未就绪，装饰退场后显示官方加载状态。隐藏时暂停，恢复后继续；15 秒累计可见故障上限用于失常媒体，正常原片不会碰到上限。首帧解码宽限为 2.2 秒可见时间；媒体失败、禁播或减少动态使用海报，原生就绪后立即清理，静态海报最多保留 4.5 秒。一直未完成的窗口另有 30 秒清理上限。

原生 `dsh-app` 转发层会移除 `Content-Length`，实测直接媒体流的 `seekable` 为 `0..0`。继续沿用上一版的本地 Blob 路径：通过原来的同源鉴权路由读取约 757 KiB 的视频，再交给 Chromium 播放。结束时中止未完成的请求、撤销 Blob URL，不修改上游签名包；本版不再设置 2.2 秒起点。

按钮「跳过动画」、Esc 或页面离开可直接清除装饰；普通键盘输入不触发跳过。原生加载页仍存在而 spinner 被错误报告替换时，装饰立即退出，让官方错误与恢复入口可见。退出时断开观察器与监听、取消计时，暂停视频、移除资源地址并停止解码；局部界面更新不重播。最早的主进程/Host 启动发生在插件加载前，仍维持官方启动体验。

原生主进程缓存本次启动的注入表，因此修改启动选项后需正常完全退出应用再打开；仅刷新窗口不能代替冷启动。macOS 的红色关闭按钮只隐藏窗口，Dock 与 `./run.sh start` 恢复同一文档，不重播。先保存工作、确认任务已结束，再 Cmd+Q 完全退出并运行启动命令；本项目不会为播放动画强制终止用户任务。

主题只改集中令牌，不替换聊天、消息、模型、文件、工具调用或任务执行组件。主题依赖官方原来的浅色/深色状态色和代码语法色。管理页每张主题预览使用与实际应用相同的 token 映射。

设置由原生 Host 与桌宠共享 `.local/appearance.json`。更新前加文件锁、重新读取磁盘并合并；写入采用原子替换。桌宠通过目录监听同步，原生插件在可见时轮询这份小型本地配置，并在卸载时清理计时器。此同步不访问会话或模型 API。

桌宠使用 `focusable:false`、`showInactive()`、透明窗口与 always-on-top；SVG 实际绘制区域参加命中检测，空白转发鼠标事件。拖拽只处理自己窗口内的指针事件；不监听全局键盘、不读屏。显示器事件后将位置约束到最近的可用工作区。退出桌宠会保存隐藏状态；隐藏时仍可从菜单栏退出，不留下缺少退出入口的后台进程。

升级 Harness 前须重新检查这些接口和原生加载页 DOM，并修改版本约束、重新跑验证；没有“支持任意版本”的承诺。
