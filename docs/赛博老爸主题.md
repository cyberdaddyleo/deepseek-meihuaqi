# 赛博老爸：蓝光启程与科技深蓝

v0.7.0 新增两个内置预设：启动画面的 **赛博老爸 · 蓝光启程**，以及界面皮肤的 **赛博老爸 · 科技深蓝**。它们与已有的 [赛博老爸桌宠](赛博老爸桌宠.md) 分别保存，可以成套使用，也可以和鲸鱼娘、森林奶油等预设自由组合。默认仍为鲸鱼娘，更新不会重置已有选择或桌宠大小。

## 选择与启动

在原生 **左下角账号菜单 → 设置 → 美化工具箱** 中：

1. 进入「启动画面」，在「赛博老爸 · 蓝光启程」卡片点击「预览」或「应用」。
2. 进入「界面皮肤」，在「赛博老爸 · 科技深蓝」卡片点击「应用」，真实界面即时换肤。
3. 如需搭配角色，进入「桌面宠物」选择「赛博老爸」。它不会随前两个选项强制切换。

从旧版更新源码后，在仓库目录执行 `./run.sh setup` 安装锁定依赖并重新构建。保存工作并等待任务结束，使用 **Cmd+Q 完全退出 Harness**，再执行 `./run.sh start`，让原生 Host 加载新的内置媒体目录。仓库路径未移动、插件已经安装时不需要重复 `install`；首次安装按 [README](../README.md#安装与启动) 执行 `setup`、`install`、`start`。

macOS 红色关闭按钮只隐藏窗口，再点 Dock 不会重播启动视频。日常演示可直接使用「预览」，不用退出后端。桌宠仍使用 `./run.sh pet` 独立运行。

## 完整原片启动

`assets/cyberdad-startup.mp4` 是用户提供的视频原片：1918×1080，约 **7.072 秒**，**32,273,103 字节**，未剪辑、未转码。科技蓝线条逐渐组成赛博老爸，实际启动和预览均从第 0 秒播放。**v0.7.1 起默认播放原片声音**，遵循系统输出音量；启动层的声音按钮只开关本次播放的声音，管理页预览可通过视频控件静音或调节音量。预览的自动播放被阻止时，点击视频播放按钮开始播放。

启动视频采用完整画面适配（`videoFit: "contain"`）。窗口比例与原片不同时，会留深蓝边，不裁掉两侧文字或角色。

后台初始化与动画并行。即使真实 Harness 提前就绪，也会等视频自然播放结束后，再淡出进入工作界面；若视频结束或主动跳过时程序还没准备好，继续显示官方加载状态。点击右下角跳过图标或按 Esc 可以主动提前进入，普通按键不会误跳过。

v0.8.2 的启动层仅在右下角保留两个 30 px 圆角小按钮、16 px SVG：左侧扬声器／静音图标开关声音，右侧跳过图标结束片头。不常显按钮文字，不显示左下角「已就绪／初始化」文案，也不添加整片底部遮罩。按钮保留读屏名称与声音按下状态，支持 Tab 聚焦、Enter 操作；SVG 和自定义图片启动页也使用同样的小跳过图标。原片视频和音轨未改，管理页预览继续使用视频原生控件。

实际启动时有声自动播放被环境策略拒绝，会先静音继续视频，显示可点击开启的静音图标，并用读屏描述说明限制原因，不显示额外文字提示；静音播放也失败才回退海报。视频故障或系统启用「减少动态效果」同样回退本地海报；初始化失败会露出官方错误与恢复入口。启动层在隐藏窗口时暂停音视频，恢复可见后继续；完成、跳过或退出时停止声音并释放媒体资源。沿用现有的加载超时机制，不循环播放，也不在切换聊天时重新播放。普通「添加」入口目前仍只支持图片，自定义视频导入不属于本次更新。

## 真实 Harness 皮肤

皮肤保留参考图中赛博老爸的圆头、圆框眼镜、蓝色耳机、白西装和伸手姿势，使用深蓝科技背景、冰蓝重点色与清晰浅色文字。主题令牌覆盖原生背景、侧边栏、会话选中状态、输入框、消息、代码区、工具卡、菜单、弹窗和按钮。

原参考图是视觉稿，包含画在图片里的按钮、标题、侧栏和输入框。实际壁纸先去掉这些静态界面元素，只保留角色与背景；所有可操作内容仍由真实 Harness 组件提供。因此最终布局遵循原生程序与窗口尺寸，不逐像素照搬视觉稿。切换主题不重新创建聊天页面，不重启后端，不清空输入草稿。
