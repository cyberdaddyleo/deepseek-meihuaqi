# 给本地 AI 助手的部署提示词

把下面整段复制给具备本地终端执行能力的 AI 助手。它需要实际检查、安装并打开应用；登录等个人操作由你完成。

```text
请在我的电脑上实际安装并启动“赛博老爸的 Harness 换装器”原生插件，不能只输出方案。

项目仓库：https://github.com/cyberdaddyleo/deepseek-meihuaqi
项目当前文档版本：v0.8.2
唯一已验证的组合：macOS Apple Silicon + 官方 DeepSeek Harness 0.2.0-rc.2。

请按以下顺序执行：

1. 先检查系统与 CPU 架构、可用磁盘空间、网络、git，以及官方 Harness 的安装位置和版本。阅读仓库 README.md、docs/接入说明.md、docs/验证报告.md。不要虚构更兼容的 Harness 版本，不要绕过 doctor 或安装器的版本检查，不要修改、替换或重新签名官方 .app。Windows、Linux、Intel Mac 或其他 Harness 版本均未实测；遇到这些情况说明限制，不要报告安装成功。

2. 若未安装 Harness，从 https://github.com/deepseek-ai/deepseek-harness 的官方来源核对并安装 0.2.0-rc.2，先打开一次完成初始化。需要登录时由我操作。若官方来源无法取得固定版本，说明阻碍，不自动改装其他版本。若我的现有版本不同，不擅自降级或覆盖应用与数据。应用不在默认位置时，为后续命令设置 HARNESS_APP 指向真实 .app 路径。

3. 选一个长期保留的目录，检查是否已有同名仓库，不覆盖我的文件。首次安装执行：
   git clone https://github.com/cyberdaddyleo/deepseek-meihuaqi.git deepseek-meihuaqi
   cd deepseek-meihuaqi
   ./run.sh setup
   setup 检查原生版本、安装锁定依赖、准备 Electron 并构建插件。run.sh 在需要时把官方 Node.js 24.19.0 下载到项目 .runtime 并校验，不需要覆盖系统 Node。检查退出状态，失败时按实际错误处理，不跳过失败继续宣称完成。

4. 确认 Harness 没有执行中的任务，先保存工作，用正常方式（macOS Cmd+Q）完全退出，不强制杀掉任务。再执行：
   ./run.sh install
   ./run.sh start
   install 通过官方插件管理能力安装本地 link 包，修改前备份相关 profile 配置。拉取源码或构建成功不等于插件安装成功，start 的打开提示也不等于界面已验证。项目目录安装后需要保留。

5. 实际打开“左下角账号菜单 → 设置 → 美化工具箱”，检查三个标签及全部预设：
   - 启动画面 6 个：极客 · 系统唤醒、赛博老爸 · 蓝光启程、鲸鱼娘 · 深蓝启航、清透蓝鲸、星河微光、森林晨光。
   - 界面皮肤 6 套：极客 · 深海中枢、赛博老爸 · 科技深蓝、鲸鱼娘 · 深蓝霓虹、清透冰蓝、星河夜航、森林奶油。
   - 桌面宠物 4 个：赛博老爸、鲸鱼娘、小蓝鲸、奶油猫。
   确认换肤改变真实原生侧边栏、输入框和菜单，不能另造聊天客户端或只打开演示网页。三个分类独立，保留已有选择、大小和位置。新安装默认鲸鱼娘启动与皮肤，桌宠默认不显示，可在桌宠标签开启。

6. 检查当前选中的启动画面。三个内置视频默认从第 0 秒完整播放约 7 秒并尝试播放素材声音；原生初始化并行，但提前就绪不能截断视频。右下角声音与跳过按钮是小图标，可切声音、点跳过或按 Esc，支持 Tab / Enter。自动播放受限可静音继续并点击开声；“减少动态效果”或媒体失败会回退海报，原生启动错误仍可见。只看到 video 节点或命令成功不能证明画面已播放，报告真实观察结果。macOS 红色关闭按钮只是隐藏，再点 Dock 或 run.sh start 不重播；修改启动选项后，保存工作、等待任务结束、Cmd+Q 完全退出再启动。可先用工具箱“预览”检查，不为演示强制结束任务。

7. 检查桌宠；依赖安装后 ./run.sh pet 可独立运行，不启动 Harness 后端。验证可见窗口、右键菜单、调大小、点击唤醒和正常退出，说明实际完成的交互。关管理窗口或“隐藏”不等于退出，需右键“退出桌宠”或菜单栏 ◉ 退出。桌宠是预设图形动作，不做 AI 对话。缺少 UI 自动化权限、锁屏或无法观察跨应用点击时，明确列为未验证；不把窗口属性或模拟 IPC 当作物理拖动、点击穿透和焦点实测。

8. 确认三个标签有“添加”入口。需要演示时先读 docs/自定义内容.md，可用 examples/小星星.svg 与 examples/紫藤轻雾.theme.json 预览，不擅自替换已有选择或留下测试预设；导入保存不自动应用。“恢复默认”保留自定义库，删除当前自定义预设只回退对应分类。不要上传我的图片、私人会话、密钥或配置，不导入未知脚本。

9. 日常启动不开调试端口。需要原生 UI 测试时，只在空闲、无私人内容的测试会话执行，先读验证报告确认副作用，完成后恢复原选择与正常启动方式。只报告本次真正运行且有结果的检查，历史报告不能冒充本次测试。不要提交 .local、.runtime、node_modules 或私有配置。

10. 最后告诉我源码实际路径、官方 Harness 实际版本、安装与启动结果、工具箱入口、实际验证与未验证项，以及启动／独立桌宠／卸载命令。提醒本地 link 安装需要保留项目目录，移动前应先卸载再安装。

常用命令以仓库最终 README 为准：
./run.sh doctor
./run.sh setup
./run.sh install
./run.sh start
./run.sh pet
./run.sh uninstall
```

更新已有安装时，保存工作、等待任务结束并 Cmd+Q 退出 Harness；旧桌宠从自身菜单彻底退出。进入原目录执行 `git pull --ff-only`、`./run.sh setup`、`./run.sh start`，目录不变无需重复安装。有本地改动或冲突时先处理，不要强制重置。新版本打开后可重开桌宠，保留原尺寸与位置。
