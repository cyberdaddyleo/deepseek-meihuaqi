# 极客：系统唤醒与深海中枢

v0.8.0 新增两个内置预设：启动画面的 **极客 · 系统唤醒**，以及界面皮肤的 **极客 · 深海中枢**。两项分别保存，可以搭配赛博老爸、鲸鱼娘、小蓝鲸或奶油猫桌宠。本次没有新增桌宠，也不把启动、皮肤和桌宠绑定；新安装默认仍为鲸鱼娘，更新保留已有选择、桌宠大小和位置。

**v0.8.1 增加首页代码终端装饰，并细化原生代码块、终端与工具卡的外观。**视频和音轨保持 v0.8.0 的用户原片，播放方式与声音开关不变。

**v0.8.2 将启动层改为小图标操作。**视频右下角显示声音和跳过图标，取消常显按钮文字、左下角初始化文案与整片底部遮罩；原片视频和音轨保持不变。

## 选择与启动

在原生 **左下角账号菜单 → 设置 → 美化工具箱** 中：

1. 进入「启动画面」，在「极客 · 系统唤醒」卡片点击「预览」或「应用」。
2. 进入「界面皮肤」，在「极客 · 深海中枢」卡片点击「应用」，真实界面即时换肤。
3. 桌宠继续在「桌面宠物」中独立选择；也可以关闭桌宠。

从旧版更新源码后，在仓库目录执行 `./run.sh setup` 安装锁定依赖并构建。保存工作并等待任务结束，使用 **Cmd+Q 完全退出 Harness**，再执行 `./run.sh start`，让原生 Host 加载新媒体目录。原仓库路径不变且已安装插件时，无需重复安装；首次安装按 [README](../README.md#安装与启动) 执行 `setup`、`install`、`start`。

依赖已安装且仅更新本次客户端代码时，也可执行 `./run.sh build`，正常 Cmd+Q 完全退出后用 `./run.sh start` 重新打开。仅关闭窗口或刷新局部页面不会替代完整退出。

若旧版桌宠仍在运行，更新目录前先从桌宠右键菜单或菜单栏选择「退出桌宠」，并 Cmd+Q 完全退出 Harness。旧伴随进程会缓存旧预设目录，需要一同重新载入；重开后可在工具箱再次开启桌宠，尺寸与位置仍保留。首次安装不需要此步骤。

macOS 红色关闭按钮只隐藏窗口，重新点 Dock 或执行启动命令不会重播片头。日常演示可使用卡片「预览」，无需退出后端。桌宠仍使用 `./run.sh pet` 独立启动。

## 原片音画完整播放

`assets/geek-startup.mp4` 原样保留用户提供的视频与音效：H.264、3184×1792，AAC-LC 44.1 kHz 双声道，约 **7.072 秒**、**38,313,745 字节**，未剪辑、未转码。实际启动和预览默认播放原片声音，播放器音量为 1，最终响度遵循系统输出音量。

启动使用完整画面适配（`videoFit: "contain"`）。窗口比例与原片不同时留深色边，保留全部 HUD 边缘。视频从第 0 秒播放，后台初始化并行；即使 Harness 提前就绪，也会等自然播放结束后再淡出。片尾若初始化仍未完成，继续显示官方加载状态。

启动层右下角是两个 30 px 圆角小按钮，内含 16 px SVG：左侧扬声器／静音图标开关本次声音，右侧跳过图标提前结束片头。按钮不常显文字，保留「开启启动声音／关闭启动声音」「跳过动画」读屏名称与声音按下状态，可用 Tab 聚焦、Enter 操作，或直接按 Esc 跳过；普通输入不会误跳过。

有声自动播放被环境策略拒绝时，启动层先静音继续，通过静音图标表示状态，可点击开启；限制原因保留在读屏描述中，不显示文字提示。静音播放也失败才回退本地海报。管理页预览仍使用视频原生控件调节声音，自动播放受限时可点击播放，不采用启动层的小图标布局。

实际启动层在窗口隐藏时暂停音视频，恢复可见后继续；结束、跳过或退出时停止声音并释放视频资源。素材缺失、解码故障或系统启用「减少动态效果」时显示海报，原生就绪后放行；初始化失败立即露出官方错误与恢复入口。沿用已有的有限加载与播放超时，不循环播放，不会因切换聊天而重新播放。

启动层不再重复显示「Harness 已就绪／正在初始化」文案，也不添加整片底部渐变遮罩。播放结束或主动跳过后，程序尚未就绪时仍显示原生加载提示；失败时仍显示原生错误。SVG 与自定义图片启动页同样使用右下角小跳过图标。

## 真实界面的极客皮肤

「极客 · 深海中枢」采用近黑深蓝基色 `#050c12`、青蓝细边、浅色文字与少量红色网络光点，背景呈现地球数据网络和细技术网格。主题令牌覆盖原生主背景、侧边栏、会话选中态、输入框、消息、按钮、菜单、弹窗、代码区和工具卡。

用户参考图含有静态按钮、日志、模型名称、时间和状态数字。运行时壁纸通过内置图像工具去掉这些元素，只保留地球与背景装饰；真实界面内容仍由 Harness 组件显示。参考图中的额外功能、日志和系统指标不作为本插件的功能，也不伪装为实时数据。最终布局遵循原生程序，不逐像素照搬参考稿。

## 首页代码装饰与真实内容

v0.8.1 的极客空白首页增加三块静态面板：带行号和语法颜色的场景代码、灵感序列、创意脚本。青蓝框线、细标题栏和红色角标与地球背景配合。它们是视觉装饰，不执行代码、不读取文件、不报告实时运行状态；面板不接收点击，真实输入框和原生交互继续使用。

布局通过 CSS anchor 对齐原生主区域、标题和输入框，不搬动真实控件。主区宽度不足 820 px 或高度不足 720 px 时收起全部首页装饰；标题上方或输入框下方可用空间不足 160 px 时，分别隐藏对应区域的整块面板，避免截断代码或遮住草稿。进入实际会话、打开设置或弹窗时也会收起。没有新增 JavaScript 轮询或持续动画。

实际聊天里的代码块、终端与工具卡使用青蓝细边、终端标题栏和克制的角标。原生复制、横向滚动、代码语法色、工具展开和运行状态逻辑继续保留；红色角标仅作装饰，不代表执行错误。管理页的极客卡片复用场景代码片段，便于预览这一变化。

首页装饰通过官方 `shell.overlay` 接入，与管理卡片预览一起集中在 `src/geek-hud.mjs`；真实代码、终端及工具卡样式在 `src/geek-content-theme.mjs`。它们仅在极客主题下启用。

## 开发检查

```sh
./run.sh build
./run.sh test
./run.sh test:geek-video
```

视频专项测试解码实际 MP4，检查音轨非静音、完整播放、声音开关、跳过、异常回退与资源释放。它验证受控启动生命周期，不能替代实际原生启动。

`./run.sh test:geek-native` 仅供开发者在已通过本机 `127.0.0.1:9224` 调试端口启动的空闲原生应用中运行，脚本会重载窗口、切换主题并验证草稿；不要在有任务运行时执行。日常启动不打开调试端口。完成后正常退出测试实例，再用 `./run.sh start` 重新打开。

`./run.sh test:geek-hud` 检查本次首页代码装饰，同样需要开启上述本机调试端口，并停留在空闲原生首页。该命令用于布局、响应式收起和交互检查，不代替视频音轨测试或真实任务验收。

实际执行结果、原生截图和未验证项统一记录在 [验证报告](验证报告.md)。本页描述设计与使用方式，不将检查命令视为测试通过记录。
